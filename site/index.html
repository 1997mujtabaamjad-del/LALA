The nine layers (v2.0)

🧑‍💼 Multi-Agent Brain

CEO delegates to Research · Coding · Vision · Finance · Scheduler · Health · Home agents.

🗄 Long-Term Memory

working · session · semantic · episodic · procedural layers + consent-gated voiceprints.

🌍 World Model

network, battery, weather, calendar, processes, IoT devices — context-aware answers.

🧭 Autonomous Planning

“prepare my interview” → researched, résumé opened, questions drafted, reminders set.

👁 Computer Vision

screen capture + OCR (“read the screen”); webcam/face/gesture ready for consent.

🪞 Digital Twin

live mirror of processes/files/devices — “what changed?” diffs your world.

🎙 Voice Pipeline

wake → STT → intent → planner → tools → response → TTS, streaming end-to-end, barge-in.

🧰 Tool Ecosystem

browser · terminal · code · email · calendar · weather · maps · finance · home · GitHub…

🦾 Robotics

pair ESP32/Pi/arms/drones via config; motion is confirm-gated.
